# 2026-07-30 开发日志

## 搭建班级教学管理平台 - Phase 1 & Phase 2

### 完成的工作

**Phase 1：基础框架（已完成）**
- 创建了完整的 Django 项目结构（config/settings 三层配置、manage.py、urls 等）
- 实现了 accounts 账户管理系统（登录、登出、密码修改、限失败锁）
- 实现了 dashboard 工作台首页（统计卡片、快捷入口、待办提醒）
- 实现了 classes 班级与学期设置模块（CRUD、归档、当前状态切换）
- 实现了 audit 操作日志模块（记录、筛选、分页）
- 配置了 Docker 环境（Dockerfile、compose.yaml、nginx）
- 创建了完整的左侧导航菜单（涵盖所有模块）
- 创建了基础模板布局（顶部蓝色导航 + 左侧固定导航 + 内容区）
- 使用 Bootstrap 5 + HTMX + Chart.js 作为前端方案

**Phase 2：学生基础数据（已完成）**
- 实现了 Student 模型（学号、姓名、性别、出生日期、身高、视力、座位需求等）
- 实现了 Guardian 模型（父亲、母亲、监护人信息、脱敏电话显示）
- 学生花名册（列表、搜索、筛选、分页、新增、编辑、软删除）
- 学生综合档案页面（标签页：基本信息、家长信息）
- 家长联系方式管理（列表脱敏、编辑）

### 技术决策
- Django 5.2 LTS + SQLite + Django Template + Bootstrap 5
- 所有业务模型继承 BaseModel（含 created_at/updated_at）
- 重要数据采用软删除（is_deleted + deleted_at）
- 操作日志记录所有关键操作

- 考试与成绩、评语、谈话、活动等
